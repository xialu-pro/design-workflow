# 图文特色楼层模板

> 本模板为自包含生成单元。AI 读取本文件后即可精确生成图文特色楼层，无需再拼凑多个组件规范。适用于左图右文/左文右图的特色介绍场景。

## 一、楼层结构

```
楼层容器（1920px 宽 / 360px 宽）
│  内容区: PC 1488px（距两边 216px）/ MB 312px（距两边 24px）
│
├── [楼层标题]（必选）
│   字号: PC 32px/44px / MB 18px/26px, 字重: SemiBold
│
├── [楼层标题描述]（可选）
│   字号: PC 16px/24px / MB 14px/22px, 字重: Regular
│
├── [标题到内容间距] 间距 7: PC 40px / MB 12px
│
└── [图文区域]（左图右文 或 左文右图）
    ├── [图片区] PC: 占 12 列（约 728px）/ MB: 占 4 列（312px）
    └── [文字区] PC: 占 12 列（约 728px）/ MB: 占 4 列（312px）
        ├── [小标题] PC 24px/32px / MB 16px/24px, SemiBold
        ├── [正文] PC 16px/24px / MB 14px/22px, Regular, --o-color-info2
        ├── [间距] 24px
        └── [按钮组] 左对齐, solid → outline → text
```

### ⚠️ 楼层容器 CSS 实现（必须严格遵守）

> 🔴 生成HTML时，楼层内容容器**必须**使用以下CSS，禁止使用1200px/1140px等框架默认值。**禁止使用 `margin: 0 auto` + `padding: 0 216px` 组合**（border-box下padding吃进max-width，内容区变窄）。

**PC端**：
```css
.floor-feature {
    width: 1488px;                    /* 内容区固定宽度，撑满 */
    max-width: 1488px;                /* 禁止 1200px / 1140px / 960px */
    margin-left: 216px !important;    /* 固定左边距 */
    margin-right: 216px !important;   /* 固定右边距 */
    padding: 0 !important;            /* 禁止用padding控制楼层边距 */
}
```

**MB端**：
```css
.floor-feature-mb {
    width: 312px;
    max-width: 312px;                 /* 禁止 360px（那是画布宽度） */
    margin-left: 24px !important;
    margin-right: 24px !important;
    padding: 0 !important;
}
```

### 精确数值

| 规格项 | PC 值 | 来源 |
|--------|-------|------|
| 图片区宽度 | 占 12 列 ≈ 728px | 栅格计算 |
| 文字区宽度 | 占 12 列 ≈ 728px | 栅格计算 |
| 图片与文字间距 | 32px（间距 6） | 硬约束 §3 |
| 图片比例 | 16:9 | card.md 规则 5 |
| 小标题字号 | 24px / 32px | 硬约束 §2（二级标题） |
| 正文字号 | 16px / 24px | 硬约束 §2（常规正文） |
| 按钮与正文间距 | 24px | 硬约束 §9（按钮上下间距） |
| 按钮尺寸 | large（40px 高） | banner.md 按钮规格 |

## 三、MB 端布局

MB 端图文特色楼层改为**垂直堆叠**：图片在上，文字在下。

```
┌────────────────────────┐
│                        │
│    图片区域             │
│    (4 列, 312px 宽)     │
│    aspect-ratio: 16/9   │
│                        │
├────────────────────────┤
│  小标题                 │
│  16px / 24px            │
│                        │
│  正文描述文字...        │
│  14px / 22px            │
│                        │
│  [solid 按钮]           │
│  medium（32px 高）       │
└────────────────────────┘
```

### MB 端精确数值

| 规格项 | MB 值 | 来源 |
|--------|-------|------|
| 图片区宽度 | 312px（4 列满宽） | 硬约束 §4.1 |
| 图片与文字间距 | 12px（间距 3） | 硬约束 §3 |
| 小标题字号 | 16px / 24px | 硬约束 §2 |
| 正文字号 | 14px / 22px | 硬约束 §2 |
| 按钮尺寸 | medium（32px 高） | banner.md |

## 四、多组图文排列

当楼层包含多组图文特色时，组与组之间的间距：

| 设备 | 组间距 | 来源 |
|------|--------|------|
| PC | 32px（间距 6） | 硬约束 §3 |
| MB | 12px（间距 6） | 硬约束 §3 |

每组图文方向（左图右文 / 左文右图）均可，按实际页面视觉效果决定。

```

□ 图片与文字间距是否为 PC 32px / MB 12px？
□ 小标题字号是否为 PC 24px/32px / MB 16px/24px？
□ 正文字号是否为 PC 16px/24px / MB 14px/22px？
□ 按钮是否左对齐？
□ Solid 按钮是否最多 1 个？
□ 按钮与正文间距是否为 24px？
```
