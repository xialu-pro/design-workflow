# 栅格 / 断点 / 间距规范

> 本文档从 `hard-constraints.md` 中提取栅格、断点与间距相关规则，作为布局设计的独立速查手册。

---

## 1. 断点定义

| 设备 | 屏宽范围 | 使用列 |
|---|---|---|
| **MB（移动端）** | 360 ~ 600px | 下方所有表格的 **MB** 列 |
| **PC（桌面端）** | > 1680px | 下方所有表格的 **PC** 列 |

---

## 2. 栅格实际布局速查

| 项 | PC | MB |
|---|---|---|
| 画布总宽度 | 1920px | 360px |
| 内容区宽度 | 1488px | 312px |
| 内容区距画布两边边距 | 216px | 24px |
| 栅格列数 | 24 列 | 4 列 |
| 水槽宽度（card 与 card 的上下左右间距） | 32px | 12px |

---

## 3. 间距 Token

| Token | PC | MB |
|---|---|---|
| 间距 1 | 4px | 4px |
| 间距 2 | 8px | 8px |
| 间距 3 | 12px | 8px |
| 间距 4 | 16px | 8px |
| 间距 5（组件左右间距） | 24px | 12px |
| 间距 6（组件上下间距） | 32px | 12px |
| 间距 7（楼层标题到楼层内容） | 40px | 12px |
| 间距 8 | 48px | 16px |
| 间距 9 | 64px | 24px |
| 间距 10（楼层之间） | 72px | 32px |

---

## 4. 合法间距集合

- **PC**：`{4, 8, 12, 16, 24, 32, 40, 48, 64, 72}`
- **MB**：`{4, 8, 12, 16, 24, 32}`

---

## 5. 落地页模板结构

| 顺序 | 区块 | 必选/可选 |
|---|---|---|
| 1 | 顶部导航 | 必选 |
| 2 | Banner | 可选 |
| 3 | 楼层（可多个） | 必选 |
| 4 | 页脚 | 必选 |

- 楼层间距统一使用**间距 10**（PC 72px / MB 32px）
- 楼层标题到内容间距固定使用**间距 7**（PC 40px / MB 12px）
