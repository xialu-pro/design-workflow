# 通用交互规范

> 本文档定义 OpenEuler 设计系统中组件的通用交互规则与禁止组合约束。

---

## 1. 按钮交互规则

| 规则 | 说明 |
|---|---|
| 对齐 | 按钮一律**左对齐** |
| 排列优先级 | 多按钮从左到右：`solid` → `outline` → `text` |
| Solid 数量 | 同组按钮中 `solid` **有且只有一个** |
| 按钮间距 | 同组水平间距**固定 24px** |
| 上下间距 | 按钮与周围内容上下间距**固定 24px** |

---

## 2. 组件与栅格

- 所有组件**必须挂靠栅格容器**，严格对齐内容区栅格列
- 禁止组件游离在页面空白区域独立摆放

---

## 3. 卡片间距

- 卡片与卡片间距**固定 32px**（PC）/ **12px**（MB）
- 禁止使用 16 / 20 / 24 / 40px 等非标准卡片间距

---

## 4. 禁止组合黑名单

| # | 禁止行为 |
|---|---|
| 1 | L-Banner 塞进卡片、弹窗、子内容区块 |
| 2 | 同一区块内 L + M + S 不同尺寸 Banner 并排 |
| 3 | 按钮放在标题/富文本上方 |
| 4 | 表单按钮分散在各表单项中间 |
| 5 | 卡片内部横向混放多种不同规格组件 |

---

## 5. 图标使用规则

| 场景 | 方式 |
|------|------|
| 组件状态图标 | 先 `ls references/assets/<组件名>/`；有 SVG → Read 后内联；无 → CSS 兜底 |
| 含图标 UI 组件 | 同上 |
| 独立图标 | 先查 `references/assets/`；无 → 查 icon-keys.md 手写 SVG |

**SVG 内嵌方式**：直接将 `<svg>` 标签写入 HTML，不使用 `<img src>`。颜色使用 `currentColor` 继承父元素色值。

---

## 6. 页面生成自动校验

```
□ Banner 尺寸与所在容器是否匹配？
□ 同区块内 Banner 尺寸是否统一？
□ 按钮排列：solid → outline → text，且 solid 唯一？
□ 按钮左对齐？
□ 按钮间距及上下间距均为 24px？
□ 所有组件挂靠栅格容器？
□ 卡片间距统一？
□ 无黑名单组合？
```
