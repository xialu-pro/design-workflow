导航下拉面板（分类平铺式）

交互模型：hover = 临时展开（鼠标移走即消失，不改变锁定状态）；click = 锁定展开（面板固定，需再次点击同一菜单项才关闭）。「开发」已锁定展开（5 列 + 右侧快捷链接栏——该栏为可选模块，看需求挂载；本页为演示检验默认渲染，正式落库时该段 HTML 默认注释掉），「社区」为当前页选中态（Regular(400) + primary1 + 底部 2px 指示线，背景透明、无字重变化——2026-10-15 用户否决设计稿标注的 Semibold：字重随交互切换会肉眼跳动）。hover 任何菜单项（含无面板的社区/下载/文档）均仅文字变 primary2，不变粗、无下划线、无背景。「代码扫描」为已选态，「发布容器」为禁用态。

多列平铺结构

主体为多列平铺：列头（分类）+ 列内条目（标题 + 说明）。典型列数：开发 Tab 5 列（贡献社区 / 构建 / 发布 / 分析 / 项目）；社区 Tab 4 列 + 右侧快捷链接栏（可选，默认不挂载）。

条目内元素

标题右侧可带外链图标 ↗（16×16，取自 references/assets/public icons/icon-外链.svg，fill="currentColor" 跟随标题态）；标题后可挂红色小标签（BETA / 新，OTag fill + danger + small）。列底部「更多项目」的右箭头取自 icon-右箭头.svg；MB 端切换箭头取自 icon-上箭头.svg / icon-下箭头.svg。全部图标禁止手写 SVG 或色块占位。

字号 / 字重分档验证

>1440px：分类列头 16px / info4，选项标题 16px / info1，选项说明 12px / info2。≤1440px：分类列头 14px / info4，选项标题 14px / info1，选项说明仍 12px / info2。
选项标题字重默认态即为 Semibold，hover / 按下全程统一 Semibold，不随交互切换（禁用态是唯一例外，回落 Regular）。

两色分级验证（条目无选中态）

条目 hover → primary2 #5177CA、按下 → primary3 #002793。条目没有选中态：面板条目是直接点击跳走的链接，不存在"当前停在这一项"的持久状态，禁止 .is-selected 或 primary1 文字色（primary1 只属于顶导触发器 is-current）。本样式 hover 只改文字颜色，全程无背景色块、无字重变化（与平铺式的整行色块是两种交互表达）。说明文字在任何状态下都保持 info2 不变。

列头无交互验证

「贡献社区 / 构建 / 发布 / 分析 / 项目」五个列头只是分组标题——不是链接、无 hover / 按下 / 选中态、无下划线、无指针手势（cursor: default）。MB 端列头才升级为左侧一级导航列的可点击项。

禁用态验证

「发布容器」为禁用态：标题字重回落 Regular（禁用不是交互态，禁止保留 Semibold）、颜色 info4；说明同步变 info4；禁止出现 hover 变色。

截断规则验证

下拉标题最多 2 行、下拉选项最多 6 行，超出显示 ...（line-clamp 四件套：display:-webkit-box / -webkit-box-orient / -webkit-line-clamp / overflow:hidden）。被截断元素需挂 tooltip 显示完整内容（复用设计系统既有 tips 组件）。

单开互斥验证

「开发」已锁定展开：此时把鼠标移到其他菜单项上，不应出现两个面板重叠；鼠标移出整个菜单后，「开发」锁定面板恢复。

触发器状态验证（全状态 Regular(400)，无字重变化）

hover 任何菜单项（含无下拉面板的「社区 / 下载 / 文档」）→ 仅文字变 primary2，不变粗、无下划线、无背景；当前选中项「社区」→ primary1 + 底部 2px 指示线（选中优先：被 hover 时仍保持 primary1）。⛔ 2026-10-15 用户打回：禁止 hover / 选中态切 Semibold——字重随交互切换会产生肉眼可见的文字跳动（与下拉条目标题「全状态统一字重」同一原则）；2026-10-14 设计稿标注的「悬停项 Semibold」已作废。⛔ 状态规则禁止用 :has() 收窄——收窄后无面板的普通菜单项连 hover 变色与 is-current 指示线都会丢失（已复现并修正）。

快捷链接栏验证（可选模块 · 本页已挂载用于演示检验）

本示例已挂载该栏以便检验；正式落库时该段 HTML 默认注释掉，看需求取消注释。规则：① 栏首必须有「快捷链接」标题，规格与分类列头一致（>1440px 16px/24px、≤1440px 14px/22px，info4）；② 栏内整体左对齐（标题 / 色块 / 卡片同一左缘），整栏靠右——`margin-left: auto` 贴栅格内容区右缘，PC 端距视口右边固定 216px（MB 端跟随 MB 栅格，栏内左对齐）；③ 纯文本项 = 灰底按钮块（宽 342px 固定 / 高 40px / 圆角 4px / --o-color-fill3 底 / 块内 link 距左 24px + 上下居中）+ 内部 OLink medium（components/link.md：整体高 34px、上下 padding 5px、左右 padding 0px、文字 14px/22px Regular，色 link1，hover 变 link2 并加下划线，按下变 link3 并加下划线；后缀图标 24×24、图文间距 4px）；④ 图+文本卡片没有背后的色块（无背景 / 无圆角 / 无内边距），左图右文、图文垂直居中、图文间距 8px，图 121×68，标题 16px/24px info1，描述 12px/18px info3。

抽屉式贴合 / 浮层遮挡验证

面板与顶导零间距（top: 100%），紧贴顶导底边像抽屉一样展开，上圆角已压平为 0（border-radius: 0 0 4px 4px）——保留 4px 上圆角会在左上 / 右上露出月牙形缺口，视觉上又"裂开"。鼠标从「开发」下移进入面板不会闪烁关闭（无间隙可穿，基类的 ::before 4px 热区桥接已关闭）；面板应浮于卡片之上，不被顶导或内容遮挡（顶导容器禁止 overflow:hidden）。

顶导阴影 / 层叠层级验证

顶导 .o-nav 有 box-shadow: var(--o-shadow-1)（0 3px 9px 0 rgba(0,18,85,0.078)，一级阴影·浮层，来源 components/navigation.md），且必须可见。⚠️ 提顶导 z-index 无效：面板是顶导的后代，而 box-shadow 属于父元素自身绘制的一部分，永远先于一切后代绘制；z-index 只在同一 stacking context 的兄弟之间比较，跨父子无效（实测：顶导 z-index 101 时接缝处仍是纯白）。正解 = .o-nav::after 补偿层（z-index: 102）在顶导内部重画同一道阴影，叠在面板之上。⚠️ 补偿层几何必须与顶导本体一致（top: 0 + height: 100%）：阴影的锐利度由源盒子高度决定，实测三种高度的接缝处像素——height: 0 完全不渲染（死代码）、height: 1px 被 9px 模糊摊成弥散斑（254，几乎不可见）、height: 100% 才与顶导自身阴影的有效透明度一致（0.055 vs 0.057）。
